# HireMap – Talent Intelligence Platform

> One Profile. Your Entire Career.

HireMap is a production-grade Talent Intelligence Platform replacing LinkedIn, Naukri, Internshala, GitHub portfolios, and PDF resumes with a **single intelligent source of truth** for student talent.

🔗 **Live Site**: [srihari1806.github.io/HireMap](https://srihari1806.github.io/HireMap/)

---

## Features

| Module | Description |
|--------|-------------|
| 🧠 Student Dashboard | TUF-style DSA rings, GitHub activity heatmap, skill stats |
| 💼 Job Hub | Smart filters, AI match %, allocation intelligence |
| 🗺️ Roadmaps | Week-by-week prep plans with interactive checklists |
| 🏫 College Reality Feed | Anonymous posts, verified placements, DNA scores |
| 💬 Community | Discord-style servers for 340+ companies |
| 📄 ATS Resume Engine | Auto-generated, keyword-scored, PDF export |
| 📊 Progress Tracker | Badges, subject mastery bars, readiness rings |
| 👤 Profile | Public talent graph with platform sync |

## Tech Stack

**Frontend**: React + TypeScript + Vite + Tailwind CSS v4 + Framer Motion  
**Routing**: React Router (HashRouter for GitHub Pages)  
**State**: Mock data layer (production: Zustand + REST/GraphQL)  
**Backend** *(planned)*: Node.js + Express + PostgreSQL + Redis + Prisma

## Getting Started

```bash
cd frontend
npm install
npm run dev
```

## Deployment

Automatically deployed to GitHub Pages via GitHub Actions on every push to `main`.
